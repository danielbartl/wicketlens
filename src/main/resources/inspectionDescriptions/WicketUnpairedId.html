Reports possible unpaired Wicket component IDs in Java and companion HTML.

Checks supported literal IDs and their full component paths. Java IDs without matching markup and markup IDs without matching Java setup appear as weak warnings. Dynamic IDs, ambiguous pairing, and unresolved attachment scopes are excluded.

WicketLens analysis is partial. These observations do not prove a runtime error. Use the gutter icon to open the report and review its scope and uncertainty.

Press Alt+Enter to correct an ID to a compatible unpaired sibling, create basic HTML for a Java component, or create basic Java setup for markup. Fixes are offered only in supported, unambiguous scopes. Review the native diff preview; generated setup may need application-specific models and behavior.

Run Code | Inspect Code for results across the project. Configure severity or disable this inspection under Editor | Inspections | WicketLens. Gutter icons can be disabled separately under Editor | General | Gutter Icons.
