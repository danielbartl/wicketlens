# WicketLens 0.1.0 Preview 1

Explore Apache Wicket component hierarchies, navigate Java and HTML, and review
possible binding problems directly in IntelliJ IDEA. This first GitHub preview
includes optional Spring analysis and six read-only agent tools through
JetBrains' built-in MCP server.

## Download and install

1. Download **wicketlens-0.1.0-SNAPSHOT.zip** from this release's **Assets**.
   Keep it zipped. GitHub's automatically generated source archives are for
   building from source; use the plugin ZIP to install.
2. In IntelliJ IDEA, open **Settings → Plugins → ⚙ → Install Plugin from Disk…**
   and select the downloaded plugin ZIP. Restart if prompted.
3. Open your Wicket project and **View → Tool Windows → WicketLens**, then select
   a Java page/panel or its paired HTML file.

No Gradle build or separate JDK installation is needed to install the ZIP.
The plugin's packaged version remains **0.1.0-SNAPSHOT**; the release tag is
**v0.1.0-preview.1**. WicketLens is not on JetBrains Marketplace yet.
The accompanying **SHA256SUMS.txt** identifies the exact plugin archive.

## Included features

- A component sidebar that follows the editor, with search, finding filters and
  subtree exploration; Java/HTML navigation and JSON context export.
- Possible unpaired-ID inspections and gutter feedback, ID completion and
  highlighting, guarded paired renames, and supported counterpart quick fixes.
- Bounded static Java analysis of fields, constants, source helpers/factories,
  inheritance, custom form components, queues and repeater templates.
- Optional Wicket–Spring inspections, bean-name completion/navigation,
  injected-dependency views, declared profile conditions and FactoryBean
  product/factory distinctions. Preview WicketTester scaffolds use an isolated
  Spring context and Mockito mocks.
- Six optional read-only MCP tools: connectivity probe, page structure,
  validation findings, component context, injected dependencies and native
  Spring inspection findings. See [client setup](https://github.com/danielbartl/wicketlens/blob/v0.1.0-preview.1/docs/mcp-client-setup.md).

## Verification and scope

- Verified baseline: **IntelliJ IDEA 2026.2.3**, build **IU-262.10968.63**, with
  **Apache Wicket 10.11.0** fixtures. Other products/versions remain unverified.
- **1,721 normal tests**, **five bundled MCP host tests**, and **20 release-checker
  tests** pass. Plugin structure/configuration checks pass; binary verification
  is **Compatible**, with four deprecated and six experimental API usages.
- The refreshed graphical sandbox uses the same plugin JAR as the release ZIP.
  Native MCP settings expose all six tools; Codex CLI **0.166.0** and Claude Code
  **2.1.314** successfully call component context through that graphical server.
  This verifies the Gradle sandbox, not a fresh installation in a normal user profile.
- Analysis is static and deliberately bounded. Unsupported/runtime behavior stays
  uncertain; profile conditions do not establish active Spring profiles or runtime
  wiring. Representative real-application accuracy/performance evaluation remains
  deferred.
- Native MCP wire cancellation does not promptly stop work in the verified host.
  WicketLens applies a 30-second deadline; reconnect after an expired session.
  See [host limitations](https://github.com/danielbartl/wicketlens/blob/v0.1.0-preview.1/docs/mcp-isolation-transport.md).
  Connected agents may send tool responses to their model provider.
