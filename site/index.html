MCP · six read-only tools

Bring component graphs and Spring wiring context into Codex or Claude Code through JetBrains' built-in MCP server, using your own client and model configuration.

  • Page structure, binding findings, and component context
  • Injected dependencies, declared profiles, and FactoryBean products
  • Native Spring findings with IDE severity and suppression

View on GitHub ↗
1

Build the ZIP

Select a Java 25 JDK, then run:

Terminal
git clone https://github.com/danielbartl/wicketlens.git
cd wicketlens
./gradlew buildPlugin

On Windows, use gradlew.bat buildPlugin.

2

Install from disk

In IntelliJ IDEA, open Settings → Plugins → ⚙ → Install Plugin from Disk…. Select the ZIP under build/distributions/ without extracting it. Restart if prompted.

3

Open a Wicket page

Open View → Tool Windows → WicketLens. Select a supported Java page, panel, or its paired HTML. Keep Follow editor on, or choose Tools → Analyze Wicket Page.

Verified baseline: IntelliJ IDEA 2026.2.3 · Wicket 10.11.0. Java 25 is required to build. Other combinations have not been verified.

A few useful answers

Know what
you're looking at.

Useful static context, with its boundaries visible.

Does WicketLens run my application?

No. It analyzes Java and HTML through IntelliJ's PSI. You can inspect supported component relationships without starting Wicket, Spring, or an application server.

What happens with dynamic or unsupported code?

The plugin retains uncertainty and explains what it cannot prove. Unknown runtime control flow or component setup can leave parts of the hierarchy unresolved. A static finding is not a runtime validity verdict.

Do I need Spring or an AI agent?

No. The component sidebar, navigation, editor feedback, supported ID editing, and JSON export work independently. Spring checks require evidence of Wicket–Spring usage; MCP integration is optional.

What stage is the project at?

WicketLens is an early-stage plugin with a verified local preview, real framework fixtures, and working IDE/client integrations. Evaluation against representative production applications and broader version combinations is still pending.
